# rizzo-pii — Python dependencies
# Tested with Python 3.11+ on Windows. All scripts force UTF-8 and resolve paths from __file__.
#
# ──────────────────────────────────────────────────────────────────────────────
# IMPORTANT — PyTorch must match your GPU.
#   • CPU-only (inference / the desktop app): the default `pip install torch` is fine.
#   • NVIDIA Blackwell (RTX 50xx, sm_120) for TRAINING: you MUST install the cu128 build,
#     the cpu/cu121 wheels do not support sm_120:
#        pip install torch --index-url https://download.pytorch.org/whl/cu128
#   • Do NOT install torchvision/torchaudio — not used here, and old versions break
#     the transformers import ("operator torchvision::nms does not exist").
# ──────────────────────────────────────────────────────────────────────────────

# ──────────────────────────────────────────────────────────────────────────────
# Versions. The app's runtime stack is PINNED, with the same numbers used by
# Dockerfile.linux, build_linux.sh, build_macos.sh, docs/BUILD.md and the Windows
# CI (tests/test_versioni_dipendenze.py checks they stay in sync). The Docker
# server image (Dockerfile) is the one deliberate exception: it runs
# transformers 5.x, hence huggingface_hub 1.x.
#   • torch stays a lower bound: the right wheel depends on the index (CPU for the
#     app, cu128 for training on Blackwell), and the builds pin 2.13.0 themselves.
#   • pymupdf 1.28.x: 2.x requires Python >= 3.11, Dockerfile.linux has 3.10.
#   • training-only tools (accelerate, wandb, plotting) are not part of any build.
# ──────────────────────────────────────────────────────────────────────────────
